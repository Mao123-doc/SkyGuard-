# Codex 指令 · 前端体验修正（第三轮）

> 前提：注入演示数据后路线已能显示，说明数据链路是通的。
> 本轮只改**展示与文案**，不动算法、不动 services。

---

## 一、必改项（8 条）

### 1. 全站中文化

把所有英文标签改成中文，**保留英文的只有技术标识符**（如 `GATE_02_G02`、`API 路径`）。

| 现在 | 改成 |
|---|---|
| `ZONE OCCUPANCY` | 分区占用率 |
| `CAMERA MONITOR` | 现场监控 |
| `DECISION BASIS` | 判断依据 |
| `EVACUATION NETWORK` | 疏散路线图 |
| `EXIT OPERATIONS` | 疏散任务状态 |
| `SAFETY DECISION ENGINE` | 安全决策引擎 |
| `ENTRY CONTROL` | 入口管控 |
| `SCENARIO MATRIX` | 情景矩阵 |
| `INPUT` | 输入 |
| `SIGNAL OFFLINE` | 视频信号未接入 |
| `feasible` | 可行 |
| `DEGRADED` | 感知降级 |
| `REJECT` | 安全拒绝 |
| `REROUTE` | 事件重构 |
| `NORMAL` | 常态运行 |
| `standby` | 备用待开 |
| `open` | 通行 |
| `closed` | 关闭 |
| `LOCAL DEMO` | 本地演示 |
| `GET /api/...` | 保留（技术信息） |

**状态下拉、按钮、提示语全部中文。**

### 2. 取消时间显示

**时段切换器去掉时间标注：**

```
现在：[进场管控 18:30–19:00] [活动进行 19:00–21:30] [散场疏散 21:30–22:00]
改成：[进场管控] [活动进行] [散场疏散]
```

**理由**：时段由人手动点击，不依赖时间，显示时间会误导。

**同时去掉顶栏、页面里所有 "当前 18:54" 这类时间提示**（如果要保留，只保留真实系统时间的时钟，不写"距离散场还有 X 分钟"）。

### 3. 首页 KPI 改为三项

```
现在：场内观测人数 / 场景区域容量合计 / 受限入口
改成：抽样估测人数 / 区域容量合计 / 建议疏散区域
```

**第一项标注来源：**

```
抽样估测人数
22,100 人
无人机抽样估测 · 采样于 16:42
```

- 若数据来自 `demo` / `simulation`，写 `演示数据`
- 若来自真实观测，写 `采样于 HH:MM`
- 若两者都没有，显示 `—` 并写 `暂无观测`

**第三项**：统计 `occupancy > 85%` 的区域数，标签写 `建议疏散区域`。

### 4. 占用率方框加阈值提示

```
占用率分档：
< 40%   正常（灰）
40–75%  注意（黄）
75–85%  高占用（橙）  ← 加「⚠ 高占用」角标
> 85%   建议疏散（红） ← 加「⚠ 建议疏散」角标 + 红色描边加粗
```

**角标位置**：方框右上角，小字。

**> 85% 的方框**：加 `animation: pulse 2s ease-in-out infinite`（2 秒呼吸，不要快速闪烁）。

### 5. 首页不需要填场地面积

检查 `PlanPage` 的活动参数表单：

```
保留：活动名称、预计人数（可选）
删除：场地面积、闸口数量（这些从场景读取，不该让用户填）
```

**如果表单里现在有"场地面积"字段，删掉。**

### 6. 无人机轮巡策略说明

在 `LivePage` 活动模式，无人飞机区域加一行说明：

```
无人机轮巡 · 每 3 分钟切换一个区域 · 优先密度最高
当前目标：江汉门集散区
```

**如果后端没有轮巡数据，前端显示静态说明文字即可，不伪造"下一站"。**

### 7. 事件统计框加标题

图里那个 "30 个事件 + 刷新" 的框，加标题：

```
事件统计 · 30 条
[刷新]
```

### 8. 401 时提示登录

点「注入演示数据」返回 401 时，toast 改成中文：

```
需要管理员权限。请先点击右上角「登录」，使用 admin 账号登录。
```

**不要显示 `Request failed with status code 401`。**
